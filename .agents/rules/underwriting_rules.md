# Underwriting & Classification Rules

## Exterior Wall Finish & Construction Class
- **STONE** &rarr; Maps to Touchstone Construction Code **`113`** (`Rubble Stone Masonry`).
- **BRICK** &rarr; Maps to Touchstone Construction Code **`111`** (`Masonry`).

## Roof Detail Classification
- Single-ply membrane (EPDM, TPO, PVC) &rarr; Code **`7`**
- Smooth BUR / Modified Bitumen &rarr; Code **`9`**
- BUR with Gravel / Tar & Gravel &rarr; Code **`6`**
- Slate &rarr; Code **`5`**
- Light metal panels (Steel, Copper, Aluminum) &rarr; Code **`4`**
- Clay / Concrete tiles &rarr; Code **`3`**
- Asphalt shingles &rarr; Code **`1`**
- Rule: Higher % wins. If tied or no %, weaker material wins.
